#   📋 Project Manager Bot для Telegram
Умный бот для управления проектами прямо в Telegram

# 🚀 Возможности
- Проекты – создание, редактирование, удаление проектов

- Задачи – добавление задач в проекты, назначение исполнителей, установка сроков

- Категории статусов – гибкая система статусов задач (например: "К выполнению", "В работе", "На проверке", "Готово")

# 🛠 Навыки
- Python 3.11+ – основной язык разработки

- TeleBot – Создание бота

- SQL – хранение данных о проектах, задачах и пользователях
# ⌨️ Доступные команды

## Основные команды
/start – начало работы с ботом
/info – список доступных команд

## Управление проектами
/new_project - используй для добавления нового проекта
/delete - используй для удаления существующего проекта
/skills - позволяет добавить навыки для проекта
/projects - выводит спсиок существующих проектов
/update_projects - позволяет изменять существующие проекты
